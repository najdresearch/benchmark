# Najd Benchmark

Source repository for task definitions, scoring contracts, baselines, and reproducible reports. The benchmark consumes versioned, approved datasets from `najdresearch/datasets`; the Arena application runs evaluations and presents results.

Keep Saudi/Arabic classification, agent tool decisions, and computer-use actions on separate scorecards. First milestone: freeze the Saudi service-request routing task contract and an independently reviewed holdout before reporting model rankings.
